> **⚠️ ВАЖНО**: Cudy AX1500 — это ДРУГОЙ роутер, и он не поддерживается.
>
> Протестирован и поддерживается только Cudy WR1500 V1.0.

## ✨ Возможности

* Современное ядро 6.18 вместо стокового 4.4
* Современный OpenWRT вместо стоковой основы на 21.02
* Упор на производительность и стабильность по сравнению со стоковым кодом,
  с учётом картофельного процессора (1 ядро на 1 ГГц, спасибо Cudy)
* Форки открытых Wi-Fi драйверов `rtw88` и `rtw89` с лучшей пропускной способностью и стабильностью
* Форк открытого Ethernet драйвера `rtl8365mb` с поддержкой современного ядра

## ⬇️ Установка

> **⚠️ ВАЖНО**: Из-за ограничений загрузчика сделать резервную копию стоковых
> разделов флеш-памяти с хоть сколько-нибудь приемлемой скоростью **НЕВОЗМОЖНО**.
> Программное обеспечение предоставляется **КАК ЕСТЬ**, и если ваш роутер сломается
> и вы потеряете MAC-адреса/данные для Cudy Cloud, восстанавливать их придётся вам самим,
> а точнее никак. Cudy Cloud данные хранятся в `bdinfo` в зашифрованном и подписанном виде,
> в единственном экземпляре. Без них вы не сможете получать обновления и пользоваться Cudy App.
> Хоть установка OpenWRT и не должна ничего сломать, **все на ваш страх и риск**.

### Простой способ

1. Убедитесь, что у вас установлен Python 3
2. Скачайте архив со [страницы релизов](https://github.com/tdrkDev/OpenWRT-WR1500/releases)
3. Подключите ПК к WAN-порту роутера
4. Задайте на ПК статический IP, например 192.168.1.50/24
5. Зажмите RESET и включите питание роутера; держите кнопку, пока индикатор не будет гореть синим+красным дольше 5 секунд, затем отпустите
6. Запустите `tftp.sh` (Linux/Mac) или `tftp.bat` (Windows)
7. Затем переподключите Ethernet-кабель в LAN-порт или используйте Wi-Fi. См. `Данные для входа`.

### Ручной способ

1. Установите TFTP-клиент на ПК.
2. Скачайте файл `*-recovery.bin` со [страницы релизов](https://github.com/tdrkDev/OpenWRT-WR1500/releases).
3. Подключите ПК к WAN-порту роутера.
4. Задайте на ПК статический IP, например 192.168.1.50/24.
5. Зажмите RESET и включите питание роутера; держите кнопку, пока индикатор не будет гореть синим+красным дольше 5 секунд, затем отпустите.
6. С помощью TFTP-клиента загрузите файл `*-recovery.bin` на роутер под именем `recovery.bin`.
7. Затем переподключите Ethernet-кабель в LAN-порт или используйте Wi-Fi. См. `Данные для входа`.

### Данные для входа

* Пользователь: `root`, без пароля.
* IP роутера: `192.168.1.1`
* Wi-Fi: см. наклейку на задней панели роутера

## ℹ️ Настоятельно рекомендуется

* Включите **Hardware Flow Offloading**.

  Это может значительно улучшить производительность сети, если у вас тариф
  400 Мбит/с или выше. В большинстве случаев трафик будет идти в обход CPU.
  См. [OpenWRT вики (английский)](https://openwrt.org/docs/guide-user/perf_and_log/flow_offloading).

* **Установите радиаторы** на SoC, Wi-Fi-чип и свитч.

  Под высокой нагрузкой они могут сильно нагреваться, а радиаторы помогают сохранить стабильную работу и максимально возможную пропускную способность. CPU начинает троттлить при 75°C.

  Учтите, что конденсаторы рядом с чипами нужно заклеить изолентой или каптоновым скотчем. Они немного выше чипов и могут касаться радиаторов, что приведет к выходу волшебного дыма, на котором работает ваш роутер:)

## ⚙️ Железо WR1500

* SoC RT8197FH-VE5-CG
  * MIPS 24Kc V8.5, одно ядро, 1.0 ГГц
  * Встроенная ОЗУ 128MB DDR2-533
  * Встроенный Wi-Fi 4 (802.11b/g/n 2T2R)
  * 2-проводной UART
    * Требуется запаять перемычки R26 и R27
    * 38400 8N1
  * Не используется:
    * 2 порта USB 2.0
    * Посадочное место под SPI-NAND на плате
* Периферия на GPIO:
  * Красный+синий индикатор сзади
  * Кнопки WPS и Reset сзади
* Флеш-память SPI-NOR XM25QH128DHIQ 16MB
* RTL8367RB 1GbE (1 WAN + 3 LAN порта)

  Подключён через порт RGMII
* RTL8832BR(E) PCIe 1.1 Wi-Fi 6 (802.11ac/ax)

## 🏭 Стоковое ПО

* Проприетарная прошивка на основе OpenWRT 21.02
* Полупроприетарное ядро Realtek 4.4
  * Исходники либо неполные, либо крайне устаревшие
  * Модули:
    * RTL8832BR -> rtk_wifi6 (Wi-Fi 5 ГГц)
    * RTL8197G -> rtl8192cd (Wi-Fi 2.4 ГГц)
    * RTL8197H -> rtl819x (Ethernet SoC)
    * RTL8367RB -> rtl819x (коммутатор 1GbE)

* Разметка флеш-памяти:

  | Имя      | Начало   | Конец    | Размер    | Описание                                    |
  | -------- | -------- | -------- | --------- | ------------------------------------------- |
  | u-boot   | 0x000000 | 0x020000 | 128 KiB   | Загрузчик Realtek v3.4.13                   |
  | cfg      | 0x020000 | 0x030000 | 64 KiB    | H601; калибровка Wi-Fi, MAC-адреса          |
  | bdinfo   | 0x030000 | 0x040000 | 64 KiB    | Зашифрованные данные Cudy Cloud, регион     |
  | firmware | 0x040000 | 0xF00000 | 14.75 MiB | ядро + rootfs                               |
  | overlay  | 0xF00000 | 0xFE0000 | 896 KiB   | Оверлей JFFS2                               |
  | reserved | 0xFE0000 | 0xFF0000 | 64 KiB    | Неизвестно, JFFS2 с файлом "default" с '0'  |
  | backup   | 0xFF0000 | 0x100000 | 64 KiB    | Неизвестно, пустой JFFS2                    |

* Режим "рекавери"
  * Зажмите кнопку reset, подключите питание, дождитесь синего+красного индикатора, отпустите кнопку
  * Теперь устройство принимает загрузку файла `recovery.bin` по TFTP на WAN-порту, IP загрузчика — 192.168.1.6.
  * После успешной загрузки устройство автоматически прошьётся и перезагрузится, без проверки подписи.
